# 続きが読みたくなる文体スキル

原稿を「読みやすい文章」から「つい読んでしまう文章」に引き上げるためのスキル。

## このスキルの前提

読みやすさと、読み進めたくなることは別の性質です。

読みやすい文章は、読者がつまずかない文章です。摩擦がありません。しかし摩擦がないことと、先を読みたくなることは同じではありません。まったくつまずかないまま、静かに閉じられる原稿があります。

このスキルが扱うのは後者、**読者を次の行へ運ぶ力**のほうです。

| | 扱うもの | 方向 |
|---|---|---|
| `readability-reviewer` | 摩擦の除去 | 減点をなくす |
| **`page-turner-style`**（このスキル） | 推進力の付与 | 加点を作る |

減点をゼロにしても、加点がなければ読者は止まります。順番としては、読みやすさを整えたあとにこのスキルを当てます。

### 着想元について

三宅香帆『文体のひみつ なぜあの人の文章はつい読んでしまうのか？』（サンクチュアリ出版、2025年）の問い —— 伝わる文章と読まれる文章は違う —— を出発点にしています。

**本スキルは同書の要約ではありません**。同書の内容を参照したい場合は原典を読んでください。以下に書かれている技法は、同書の主張の再現ではなく、本リポジトリの原稿に適用できる形で整理し直したものです。

## このスキルを使うタイミング

- 章の下書きができて、通しで読めるようになったとき
- 書けているはずなのに、読み返すと退屈だと感じるとき
- 説明は正確だが、読者が途中で閉じそうだと感じるとき
- `readability-reviewer` を当てたあとの、仕上げの一手として

書き始める前には使いません。書き始める前は `book-writing-policy` です。

## 最初にやる診断：骨だけ読み

書き換えの前に、原稿のどこで読者が止まるかを特定します。

**各節の冒頭2文と末尾1文だけを抜き出して、順に並べてください**。本文は読みません。

この抜き出しだけを上から読んで、次の節を読みたくなるかを判定します。ここで手が止まる箇所が、読者が本を閉じる箇所です。本文の出来とはあまり関係がありません。冒頭と末尾だけで決まります。

判定の基準は3つです。

 1. 冒頭2文に、読者が答えを知りたくなる欠落があるか
 2. 末尾1文が、次に続く気配を残しているか
 3. どの節も同じ形で始まっていないか

3つとも満たしていない節から手を入れます。全部を直す必要はありません。

## 引きを作る7つの技法

### 技法1: 冒頭で情報を全部出さない

節の冒頭で結論をすべて言ってしまうと、読者はその節を読む理由を失います。**欠落を1つ残します**。

- ❌ 全部出ている:「水風呂は15〜18度が一般的で、初回は30秒から1分入れば十分です。」
- ⭕ 欠落がある:「水風呂で最初につまずくのは、温度ではありません。」

技術書では結論を先に出すのが原則です。この技法はそれと矛盾しません。**出すのは結論、伏せるのは理由や条件**です。結論を伏せて焦らすのは、次の「やらないこと」に当たります。

### 技法2: 節の末尾を閉じきらない

末尾を「〜です。」で完全に閉じると、そこが本を置く場所になります。次に続く気配を1行残します。

- 閉じている:「以上が1セットの組み立て方です。」
- 続いている:「ここまでは、どう入るかの話でした。ここからは、入らない判断の話をします。」

大げさな予告は不要です。次に何が来るかを1行示すだけで、読者は次の見出しへ進みます。

### 技法3: 長短のリズムを設計する

一文の長さが揃うと、内容にかかわらず単調になります。**長い文の後に短い文を置きます**。特にキメたい箇所は短くします。

> 座る場所でも体感は変わります。サウナ室は上の段ほど熱くなります。初回は下の段に座ってください。同じ6分でも、上段と下段では体にかかる負荷がまったく違います。

段落の最後を短文で締めると、そこが読者の記憶に残ります。逆に、長文で締めた段落は印象に残りません。

### 技法4: 語り手の判断を出す

中立で正確な説明文は、読み飛ばされます。誰が書いても同じ文章だからです。**著者の判断・立場・迷いを混ぜると、読者は書き手の像を追いはじめます**。

- ❌ 誰でも書ける:「3セットが一般的とされています。」
- ⭕ 語り手がいる:「『サウナは3セットが基本』とよく言われます。これは通説です。守らなければいけない決まりではありません。」

判断を出すことと、断定することは違います。健康・安全の記述で断定してよいわけではありません（`book-writing-policy` 方針1が優先します）。

### 技法5: 読者の反論を先回りする

読者が心の中で言い返した瞬間に、文章は止まります。**言い返される前に、こちらから言語化します**。

> 長く入るほど良いというものではありません。

> サウナ上がりの一杯を楽しみにしている方も多いと思います。順番だけは守ってください。

反論を潰すのではなく、いったん認めてから進みます。認められた読者は読み続けます。

### 技法6: 予告と回収を対で置く

前の章で置いた言葉を、後の章で回収します。読者は回収された瞬間に、本全体を1つのものとして認識します。

 * 予告:「これは第3章で効いてきます」
 * 回収:「第2章で、負荷をかけて抜く、と書きました。あれをそのまま作業に持ち込みます」

**予告したものは必ず回収してください**。回収されない予告は、読者の中で未解決のまま残ります。原稿を通しで読むとき、予告と回収の対応表を作って確認します。

### 技法7: 段落の入口を揃えない

「そして」「また」「さらに」が段落の頭に連続すると、読者は同じ景色が続いていると判断して速度を上げます。速度が上がった読者は、そのまま読み飛ばして本を閉じます。

段落の入口は、意識的にばらけさせます。

 * 具体名詞から:「砂時計が置いてある施設が多くあります。」
 * 逆接から:「ただし、時間は目安でしかありません。」
 * 短い断定から:「マナーは4つです。」
 * 問いから:「では、何セット入ればよいのでしょうか。」

## やらないこと

「続きが読みたくなる」を、次の方法で達成してはいけません。本書のトーンが崩れます。

 * **煽りで引っ張らない**。「衝撃の事実」「知らないと損する」は使いません（`book-writing-policy` 方針3）
 * **結論を出し惜しみしない**。読者に手順を渡すのが本書の目的です。焦らして読ませるのは目的に反します
 * **安全に関する記述で技巧を使わない**。危険を避ける行動は、引きを作らず、最短で言い切ります
 * **感嘆符と太字で盛らない**。強調が多い原稿は、強調していないのと同じです
 * **体言止め・倒置を多用しない**。1節に1回までにします。連続すると詩のようになり、技術書として読みにくくなります

引きは、技巧ではなく構造で作ります。冒頭の欠落、末尾の気配、語り手の判断。この3つで足ります。

## Re:VIEW原稿での使いどころ

 * **コラム（`===[column]`）を引きに使う**。本筋から少し外れた話を挟むと、読者の速度が変わり、集中が回復します
 * **見出しに欠落を作る**。「水風呂の入り方」より「水風呂に入れなくてもいい」のほうが、読者は本文へ進みます
 * **表（`//table`）の直前に1文置く**。表だけが置かれると読者は飛ばします。何を読み取ればよいかを1行で示します

## 他スキルとの関係

| スキル | タイミング | 観点 |
|---|---|---|
| `book-writing-policy` | 執筆前・執筆中 | 何を書くか、何を書いてはいけないか |
| **`page-turner-style`**（このスキル） | 下書き後 | 読者を次の行へ運ぶ力 |
| `readability-reviewer` | 下書き後 | つまずきの除去 |
| `tadaken3-style` | ブログ・note執筆時 | 著者本人の文体特徴 |

推奨する順番は **`readability-reviewer` → `page-turner-style`** です。摩擦を取ってから推進力を足します。逆順だと、引きを作った箇所を読みやすさの修正で潰してしまいます。

方針が衝突したときは、**`book-writing-policy` が常に優先**します。特に方針1（健康・安全）と方針3（煽らない）は、このスキルより上位です。

## チェック項目

- [ ] 骨だけ読み（各節の冒頭2文＋末尾1文）で、最後まで読み進められるか
- [ ] 冒頭で情報を全部出してしまっている節はないか
- [ ] 「以上です」「〜でした」で閉じきっている節末はないか
- [ ] 一文の長さが揃いすぎていないか。段落の末尾は短文で締まっているか
- [ ] 誰が書いても同じになる説明文が続いていないか
- [ ] 読者の反論を先回りしている箇所が、章に1つ以上あるか
- [ ] 予告した内容が、後で必ず回収されているか
- [ ] 段落の頭に「そして」「また」「さらに」が連続していないか
- [ ] 引きを煽りで作っていないか（`book-writing-policy` 方針3に違反していないか）
- [ ] 体言止め・倒置が1節に2回以上出ていないか

## このスキルが起動されたときの手順

1. 対象ファイルを確認します。指定がなければ聞きます。
2. **骨だけ読みを最初に実行します**。各節の冒頭2文と末尾1文を抜き出して並べ、どこで読者が止まるかを特定します。結果を先に提示します。
3. 止まる箇所を優先度順に並べます。全部は直しません。上位3〜5か所に絞ります。
4. 各箇所について、技法1〜7のどれを当てるかを示し、書き換え案を原文と併記します。
5. 出力前に「やらないこと」の5項目を自己チェックします。煽りに転んでいないか、安全記述に技巧を持ち込んでいないかを必ず確認します。
