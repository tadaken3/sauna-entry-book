# 本書の執筆方針

本書の章を書く・リライトする・レビューするときに必ず参照する執筆ルール。

## 本書の背骨（最優先）

本書には、著者本人のストーリーという背骨があります。章をまたいで、この順番で流れます。詳細は `notes/interview-brief.md`。

 1. 「全身が宙に浮くような、ぼわーんとした感覚」を初めて味わう
 2. サウナにハマる
 3. 体調を崩した経験から、無理をしなくなる
 4. 正しい知識を学ぶ
 5. サウナ・スパ健康アドバイザーを取得する
 6. 自分が学んだことを初心者へ伝える ← 本書

**どの章を書くときも、この流れのどこに位置するかを確認してから書きます。** 背骨から外れた章は、情報としては正しくても本書には不要です。

### コアメッセージの扱い

本書の根底にあるメッセージは **「サウナに入ると、人生すべてうまくいく。」** です。

これは著者の実感を表した言葉であり、**健康効果の主張ではありません**。扱い方を間違えると、方針3（煽らない）と方針1（断定しない）の両方に違反します。次のルールを守ります。

- ⭕ 著者の枠の中で使う:「私にとって、その手段がサウナでした」「私はこれを『人生すべてうまくいく』と表現しています」
- ⭕ 意味を必ず説明する:「文字どおり何もかも解決するという意味ではありません」
- ❌ 読者への効果として展開しない:「あなたの人生もうまくいきます」
- ❌ 根拠として使わない:「だからサウナは健康にいいのです」

このフレーズは、はじめに・第1章・おわりにで使います。本文の説明部分では持ち出しません。

### 読後に目指す状態

最後のページを閉じた読者が **「よし、サウナ行ってみよう。」** と思うこと。知識を覚えて終わる本にはしません。各章を書き終えたら、その章が読者をこの状態に一歩近づけたかを確認します。

## このスキルを使うタイミング

- 新規章を書き起こすとき
- 既存章を加筆・リライトするとき
- AI生成の下書きを本書のトーンに揃えるとき
- 原稿レビューで方針への準拠を確認するとき

## 文体の基本ルール

### 一人称と語尾

- **一人称: 「私」**
- **語尾: ですます調で統一**（箇条書きの体言止めは例外）
- 「だ・である」調や言い切りは混ぜない

### 著者の声を出す

著者本人 (`tadaken3-style` スキル参照) の文章特徴を、ですます調に変換した上で持ち込む。具体的には次の3点。

#### 1. 体験談を起点にする（できる限り）

各章・各節の導入で、著者自身の体験・失敗・気づきから書き起こす。必須ではないが、置けるなら置く。

例:
> 私が初めて水風呂に入ったとき、10秒ももちませんでした。冷たいというより痛い。すぐに出て、これのどこが気持ちいいのだろうと本気で思ったのを覚えています。

抽象論からいきなり始めない:
> ❌「サウナには自律神経を整える効果があるとされています。」
> ⭕「金曜の夜、頭が働かなくなったまま帰宅する日が続いていました。そのとき同僚に連れて行かれたのが、駅裏の銭湯でした。」

#### 2. 短い文を重ねてリズムを作る

一文は短く。読点で長く繋がない。結論を先に出して、説明を後ろに重ねる。

例:
> 初回は1セットで十分です。3セットは通説にすぎません。まずは、サウナ室を出るタイミングを自分で決められるようになることが先です。

長文の例（避ける）:
> 初回については、3セットが基本とよく言われていますが、これはあくまで通説にすぎないため、まずはサウナ室を出るタイミングを自分で決められるようになることを優先したほうがよいでしょう。

#### 3. 「原則は同じ／定義が違う」型の対比を効果的に使う

著者の文章に特徴的な構造。**「やっていることの本質は変わらないが、見え方・道具・前提だけが変わった」**という対比で章のキメを作る。

例:
> サウナも仕事も、やっていることは「負荷をかけて、抜く」の繰り返しです。違うのは、抜くタイミングを自分で決められるかどうかだけです。

各章に1〜2回、節レベルで使えると効く。

## 4つの内容方針

### 方針1: 体験談と客観的事実を、はっきり分ける

本書の説得力は体験談から来ます。同時に、体験談を事実のように書くと読者を危険にさらします。**この2つは文中で見分けがつく形にします。**

| | 書き方 | 例 |
|---|---|---|
| 体験談 | 一人称。時期・場所・状況を添える | 「私の場合は、休憩の椅子に座ったときに全身が宙に浮くような感覚になりました」 |
| 客観的事実 | 主語を著者から外す。必要なら出典を脚注で示す | 「一般的なドライサウナは80〜100度に設定されています」 |
| 効果の話 | 体験の枠から出さない | 「サウナに行った日は寝つきがよくなりました。私の場合の話です」 |

**根拠を確認できない健康効果は書きません。** どうしても触れる必要があるときは、出典を脚注（`//footnote`）で示し、読者が自分で確認できる形にします。出典を確認できないなら、その記述ごと落とします。

- ❌ 効果の断定:「サウナに入れば自律神経が整います」「睡眠の質が上がります」
- ❌ 曖昧な逃げ:「体調には気をつけましょう」「無理のない範囲で」
- ❌ 伝聞の事実化:「〜と言われています」で出典を示さないまま断定に近づける
- ⭕ 体験として:「私の場合は、サウナに行った日の夜は寝つきがよくなりました。個人差があります」
- ⭕ 行動は言い切る:「飲酒後にサウナに入るのはやめてください。アルコールが抜けるまで、その日は入らない判断をします」

危険を避けるための行動は、曖昧にしません。**効果は控えめに、行動は言い切る。** これが本書の書き分けです。

次の3つは、該当箇所で必ず明記します。

1. 持病・服薬・妊娠中の方は、事前に医師へ相談すること
2. 異変を感じたら、我慢せずにすぐ出ること
3. 本書は健康効果を保証するものではないこと

### 方針1の補足: 「サウナ・スパ健康アドバイザー」の扱い

著者はサウナ・スパ健康アドバイザーの資格を持っています。これは**事実として書いてよい**情報です。むしろ、学んだ経緯として背骨の一部です。

ただし、**医学的な助言の権威付けには使いません**。この資格は医師免許ではありません。

- ⭕ 経緯として:「体調を崩した経験から勉強を始め、サウナ・スパ健康アドバイザーの資格を取りました」
- ❌ 権威として:「サウナ・スパ健康アドバイザーの立場から言うと、サウナには〜の効果があります」

資格を書いた箇所の近くに、「私は医師ではありません」という一文を必ず残します。

### 方針2: できるだけ具体的で実践的な内容にする

抽象論・概念論に逃げません。読者が求めているのは「今週末、失敗せずにサウナに入る」という具体的な成果です。

すべての指示には次のいずれかを添えます。

- **数値**: 温度（サウナ室90度／水風呂17度）、時間（6分）、回数（初回は1〜2セット）、金額（入浴料500〜1,500円）
- **手順**: 「受付でタオルセットを借りる → ロッカーの鍵を受け取る」レベルまで分解する
- **判断の閾値**: 「息苦しさを感じたら、時間に関係なく出る」のように、行動を切り替えるトリガーを示す
- **失敗例**: 「体を拭かずに水風呂に入ると、周囲に嫌がられる」など、つまずきポイントを先回りで言語化する

❌ NGパターン:
> 「適度な時間で切り上げましょう。」
> 「水分補給を心がけてください。」

⭕ OKパターン:
> 初回のサウナ室は6分を目安にします。90度前後の一般的なドライサウナであれば、6分で汗は十分に出ます。時計が見えない配置なら、砂時計が落ちきる前でも出て構いません。

> 水分は入る前にコップ1杯、セットの合間に1杯、上がってから1杯の計3回を目安にします。喉が渇いてから飲むのでは遅い、という順番だけ覚えておけば十分です。

### 方針3: 文章で煽りすぎない

読者は誇大表現を警戒する層です。淡々と、しかし具体的に書きます。

| ❌ 煽り表現 | ⭕ 淡々とした表現 |
|---|---|
| 「人生が変わるととのい体験」 | 「外気浴で3分座っていると、呼吸が落ち着いてきます」 |
| 「最強のサウナ施設」 | 「水風呂と外気浴が揃っていて、平日1,000円以下で入れる施設」 |
| 「絶対にととのう入り方」 | 「初回でつまずきにくい入り方」 |
| 「サウナで疲労が完全回復」 | 「私の場合は、翌朝の目覚めが軽くなりました」 |

書名や章タイトルには多少のフックを許容します。ただし本文内では一貫して落ち着いたトーンを保ちます。

感嘆符（！）は1章につき2〜3回まで。多用しません。

#### 目指す距離感

**「サウナ好きのエンジニアが、自分の体験を交えながら友人にサウナを勧めている」くらいの距離感**で書きます。

専門書のように堅くしません。同時に、勧誘のようにも書きません。友人に勧めるとき、人は相手が失敗しないように注意点も一緒に渡します。本書もそうします。

### 方針4: サウナ用語は初出で必ず開く

読者はサウナ未経験者です。コミュニティ内で通じる言葉を、説明なしで使いません。

初出時に一言で定義してから使う語の例:

- ととのう
- ロウリュ／アウフグース
- サ活
- シングル（水風呂の温度が10度未満であること）
- ホームサウナ

2回目以降はそのまま使って構いません。定義の重複は読者の負担になります。

## 既存スキルとの関係

| スキル | タイミング | 観点 |

| **`book-writing-policy`**（このスキル） | 執筆前・執筆中 | 文体、安全記述、具体性、トーン |

役割を混ぜない。執筆前はこのスキル、執筆後は `readability-reviewer`。

## レビュー時のチェック項目

このスキルが起動されたら、以下を順に確認します。

### 文体チェック

- [ ] 一人称が「私」で統一されているか
- [ ] ですます調で統一されているか（言い切り・である調が混入していないか）
- [ ] 一文の平均長は短いか（読点2つ以上の長文が連続していないか）
- [ ] 抽象論からいきなり始まっていないか
- [ ] 「原則は同じ／定義が違う」型の対比が章のどこかにあるか（必須ではないが効くなら入れたい）

### 内容チェック

- [ ] 健康効果を断定していないか（「〜が整います」「〜が改善します」）
- [ ] 危険を避ける行動が、曖昧にならず言い切られているか
- [ ] 温度・時間・回数・金額のいずれかの数値が添えられているか
- [ ] サウナ用語が初出で開かれているか
- [ ] 煽り表現（最強・人生が変わる・絶対）が本文に紛れ込んでいないか
- [ ] 感嘆符の数が章あたり2〜3回以内に収まっているか
- [ ] 体験談と客観的事実が、文中で見分けられる形になっているか
- [ ] 出典を示せない健康効果の記述が残っていないか
- [ ] 資格を医学的助言の権威付けに使っていないか
- [ ] コアメッセージを読者への効果として展開していないか
- [ ] この章は、読者を「よし、サウナ行ってみよう」に一歩近づけたか
- [ ] 次の3点と矛盾していないか（`preface.re` に明文化はしていないが、本書が通しで守る前提）
  - 抽象論で終わらせない。温度・時間・金額といった数字で示す
  - 特別な道具は要らない。身体ひとつで行ける
  - リスクには正面から触れる。無理に「ととのう」ことは勧めない

## このスキルが起動されたときの手順

1. 対象（新規執筆 / リライト / レビュー）を確認します。
2. **新規執筆の場合**: 章のテーマ・著者の体験エピソード・伝えたい原則を聞いた上で、構成案を先に提示してから本文を書きます。
3. **リライトの場合**: 既存原稿を文体・内容の両面で評価し、違反箇所を指摘してから書き換え案を出します。
4. **レビューの場合**: チェック項目を上から当て、行番号と修正案を併記します。
5. 出力前に必ず「煽り表現チェック」「文体チェック」「安全記述チェック」を1往復行います。
