## 埋めてほしいもの

### 1. 候補施設の一覧（まずはここから）

サ活の回数が多い順、または「人に勧めたい順」で10軒ほど。この段階では施設名とエリアだけでよい。ここから絞り込む。

```
1. 施設名 / エリア（最寄り駅） / 訪問回数
2.
3.
```

### 2. 掲載する施設の詳細（絞り込んだあと）

第5章に載せる施設ごとに、以下を埋める。**空欄のまま原稿に書かない。** 数値が埋まらない項目は、その施設を落とすか、項目ごと落とす。

```
施設名（正式名称）:
エリア・最寄り駅:
料金:              （平日 / 休日 / 深夜料金があれば）
料金の確認日:       （YYYY-MM-DD。本文に「執筆時点」として明記するため）
サウナ室の温度:
水風呂の温度:
休憩スペース:       （外気浴の可否、椅子のおおよその数）
営業時間:
定休日:
電源:              （あり／なし。あるなら座席のどのあたりか）
Wi-Fi:             （あり／なし）
滞在時間の上限:
著者のひとこと:     （なぜ勧めるか。1〜2行。ここがいちばん大事）
初めて行った時期:
だいたいの訪問回数:
```

### 3. 章の構成に対応させる

第5章は次の3つの軸で節を分ける予定。どの施設をどこに置くかを決める。

| 節 | 選ぶ基準 | 該当する施設 |
|---|---|---|
| 初めての1軒目に | 水風呂と休憩スペースがあり、料金が高くない。初心者が気後れしない | TODO |
| ひとりでじっくり過ごしたいとき | 静か。滞在時間に余裕がある | TODO |
| 作業もしたいとき | 電源・Wi-Fiがある（第6章と対応） | TODO |

各節に2〜3軒ずつで、合計6〜8軒を想定している。

## 注意点

- **料金・営業時間・設備は変わる。** 本文には必ず確認日を明記する。読者が古い情報で行って困らないようにする
- **実名掲載の可否を判断する。** 施設名を出すこと自体は問題ないが、批判的な記述を含める場合は書き方に注意する。本書は勧める本なので、勧めない施設は載せない方針でよいはず
- **写真は使えないことが多い。** 浴室内・脱衣所の撮影はどの施設でも禁止。外観や館内の共用部であれば施設の許可を得られる場合がある
- **網羅性は狙わない。** 「関東の名店50選」ではなく、著者が実際に通った施設だけを理由つきで挙げる。それが本書の価値になる

## 第6章（サウナ駆動開発）との関係

第6章では「作業できる施設の見分け方」を評価軸として渡し、第5章では実例を挙げる。**両者の評価軸は一致させる。** 第6章で挙げた項目が第5章の施設紹介に無いと、読者は照合できない。

第6章で使う予定の軸は次のとおり。

 * 電源の有無（座席あたりの口数）
 * Wi-Fiの有無と実測速度
 * 作業スペースの形（デスク／リクライニング／コワーキング併設）
 * 滞在時間の上限と延長料金
 * 静かさ（テレビの有無、館内放送）

Wi-Fiの実測速度は、次に行ったときに測っておくと本書独自の情報になる。他のサウナ本には載っていない。
