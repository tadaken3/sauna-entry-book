# 章立てメモ

`catalog.yml` に反映済みの構成と、その意図をまとめる。構成を変えるときは、まずこのファイルを更新してから `catalog.yml` と `contents/` を追従させる。

## 本書のゴール

**エンジニアがサウナを、入り方から施設探し、作業場所として使うところまで自分で回せるようになる。**

サウナの入門書はすでにたくさんある。本書の差別化は「エンジニアが書いている」という一点。具体的には第3章（サウナ駆動開発）と第4章（サウナイキタイの使い方）が、他のサウナ入門書にはない部分。

## ターゲット読者

- サウナに興味があるエンジニア（未経験から、すでに通っている人まで）
- 作業できる場所としてサウナ施設を使ってみたい人
- 施設を人のおすすめではなく、自分の条件で探せるようになりたい人

読者の幅が広いので、第1章・第2章（未経験者向け）と第3章以降（経験者向け）で読み手が変わる。`preface.re` の「本書の読み方」で導線を分ける。

### 判型をA5で確定した経緯

エッセイ寄りの内容なので持ち歩けるサイズにしたい、という意図から一度B6（128×182mm）に変更した。その後、印刷所の基本仕様（B5・A5・B6・A4）を確認したうえでA5に戻して確定。

A5は同人誌の標準判型として扱われており、印刷所の選択肢・表紙テンプレート・入稿事例がもっとも揃う。B6も入稿自体は可能だが、標準から外れるぶん確認事項が増える。

検討したが見送った判型は次のとおり。

| 判型 | サイズ | A5比の面積 | 見送った理由 |
|---|---|---|---|
| B6 | 128×182mm | 0.75倍 | ページ数が約1.3倍。標準判型から外れる |
| A6 | 105×148mm | 0.5倍 | ページ数が約2倍。束が厚くなり逆に持ちにくい |
| B5・A4 | 182×257mm／210×297mm | 1.5倍／2.0倍 | 持ち歩く方向と逆 |

## 執筆アイデアと章の対応

著者から出た執筆アイデアを、どの章に配置したかの記録。

| アイデア | 配置先 |
|---|---|
| なぜ、サウナがいいのか | 第1章 |
| サウナ愛を語る | 第1章 |
| 筆者のサウナとの出会い | 第1章（冒頭） |
| サウナ駆動開発（サウナ施設での開発作業） | 第3章 |
| サウナ入力法 | 第2章（「サウナ入浴法」と解釈。※要確認） |
| サウナイキタイの使い方 | 第4章 |
| 関東で筆者のおすすめのサウナ施設 | 第5章 |
| お得にサウナに入る方法（回数券・ふるさと納税・株主優待） | 第6章 |
| 愛用のサウナグッズ（実用／ファングッズ） | 第7章 |
| （アイデアには無いが本書の方針上必須）安全のライン | 第2章の1節 |

## 検討中・未決事項

- **「サウナ入力法」の解釈**：「サウナ入浴法」と読んで第2章に配置した。もし「サウナ室でのテキスト入力」など別の意図なら第3章に移す
- **安全の扱い**：アイデアには挙がっていないが、`book-writing-policy` の方針1により第2章に1節として入れた。独立章にするかは要判断
- **施設の実名掲載**（第5章）：載せるなら掲載可否の確認が必要か判断する
- **株主優待の情報**（第6章）：優待内容・必要株数・権利確定月は変わる。一次情報で確認し「執筆時点」を明記する。投資判断を勧める書き方にはしない
- **サウナイキタイの画面キャプチャ**（第4章）：掲載可否を確認する
- **写真**：浴室内は撮影不可の施設が大半。グッズは私物を自分で撮る
- **第5章の「関東以外」節**：章タイトルと矛盾する。入れるなら1節で収める
