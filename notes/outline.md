# 章立てメモ

`catalog.yml` に反映済みの構成と、その意図。構成を変えるときは、まずこのファイルを更新してから `catalog.yml` と `contents/` を追従させる。

体験談の一次資料は `notes/interview-brief.md`（第1回・第2回インタビュー）。ここに無い体験・数値を創作しない。著者からの執筆指示書は `notes/writer-guide.md`。

## 本書のゴール

**最後のページを閉じた読者が「よし、サウナ行ってみよう。」と思うこと。**

知識を覚えて終わる本にはしない。根底にあるメッセージは「サウナに入ると、人生すべてうまくいく。」だが、これは著者の実感であって健康効果の主張ではない（扱い方は `book-writing-policy` の「コアメッセージの扱い」）。

## 構成の原則：著者のストーリーが背骨

章立ては、トピックの網羅ではなく**著者のストーリーの順番**で組んだ。

| ストーリー | 対応する章 |
|---|---|
| 「宙に浮くような感覚」を初めて味わう | 第1章 |
| サウナにハマる／巡ることが趣味になる | 第1章・第4章 |
| 体調を崩し、無理をしなくなる | 第2章 |
| 正しい知識を学ぶ／資格を取る | 第2章 |
| 学んだことを初心者へ伝える | 第3章以降すべて |

**第2章に安全を置いたのが、今回の構成のいちばんの判断。** 一般的な入門書なら安全は巻末の付録に回るが、本書では著者が実際に体調を崩しているため、その失敗談が第2章の導入になる。説教ではなく物語として読める位置に置いた。

読者側の導線も、著者が希望した順番と一致している。「まず最低限の知識を身につけて、そのうえで実際に行く」。

## 読者にたどってほしい順番

 1. 最低限の知識を身につける（第2章）
 2. 身体ひとつで行く。グッズは揃えない（第3章）
 3. できれば一度ひとりで行き、自分にとって気持ちのいい入り方を探す（第3章）
 4. サウナイキタイで「次はどこへ行こう」と調べ始める（第4章）
 5. 巡ること自体が趣味になる（第4章以降）

## 検討中・未決事項

- ~~**「サウナ入力法」の解釈**~~：第2回インタビューで「サウナ入浴法」と確定。第3章のままでよい
- **章番号の呼び方**：第2回インタビューの口述では「第一章＝入門、第二章＝サウナ駆動開発」と語られている。本書の構成はこのファイルの8章立てが正で、口述の章番号は素材の優先順位として読む
- **第5章に載せる施設数**：候補は8軒（朝霞「和」／あづま湯／サウナ横綱／キング＆クイーン／サウナ東京／サウナしきじ／末広湯／蔵の湯）。10ページで8軒は薄くなるので、厚く書く軒数を決める
- **ヨッピー氏の記事の特定**：第1章で出典として参照している。タイトル・媒体・URLが確認できない場合、本文の記述ごと調整が必要
- **『サ道』の書誌情報**：出版社・刊行年を脚注に入れる
- **施設の実名掲載**（第5章）：載せるなら掲載可否の確認が必要か判断する
- **株主優待の情報**（第7章）：優待内容・必要株数・権利確定月は変わる。一次情報で確認し「執筆時点」を明記。投資判断を勧める書き方にはしない
- **サウナイキタイの画面キャプチャ**（第4章）：掲載可否を確認する
- **写真**：浴室内は撮影不可の施設が大半。グッズは私物を自分で撮る
- **サウナ東京の設備情報**（第5章）：サウナ名称（「蒸喜乱舞」「瞑想」など）・種類・収容人数・江戸時代の入浴文化を再現した設備は、公式情報で裏を取ってから書く
- **ふるさと納税の返礼品**（第7章）：サウナ東京・草加健康センターほか。返礼品は入れ替わるため執筆直前に確認し「執筆時点」を明記する
- **施設の料金・営業時間・早朝料金**（第5章・第7章）：変動する。執筆時点を明記する
